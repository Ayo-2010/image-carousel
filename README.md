# Wanderlust Carousel

A touch-friendly image slideshow.

## Features

- Previous, next, dots and thumbnail navigation
- Autoplay with a progress bar
- Keyboard arrows and swipe gestures
- Fullscreen mode

## Running it

Open `index.html` in a browser. There is no build step and no dependencies to install.

## Files

```
index.html   markup
styles.css   styling
script.js    behaviour
```

## Tech

Plain HTML, CSS and JavaScript.
